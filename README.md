# Pagerless Homebrew tap

Formulae for [Pagerless](https://github.com/a-hagi613/pagerless).

## kubectl-page

`kubectl-page` is the `kubectl page` plugin: it starts, lists, and shows
Pagerless Pages.

```sh
brew install a-hagi613/tap/kubectl-page
kubectl page version
```

Pagerless must already be installed in the cluster. Install the chart with

```sh
helm install pagerless oci://ghcr.io/a-hagi613/charts/pagerless \
  --namespace pagerless --create-namespace --version 2.0.0
```

Each formula is generated by `scripts/release/homebrew-formula.sh` in the
Pagerless repository from that release's checksum file. Do not edit
`Formula/kubectl-page.rb` by hand.
